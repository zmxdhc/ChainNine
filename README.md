## Installation

1. Clone the repository: `git clone https://github.com/Anabelengil/ChainNine.git`
2. `cd ChainNine`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure ChainNine, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
